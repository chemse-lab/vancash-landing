# VanCash ERP

صفحة عربية RTL لمحلات الهواتف والإكسسوارات في الجزائر.

- الصفحة التعريفية: https://chemse-lab.github.io/vancash-landing/
- الدخول إلى البرنامج: https://mobileposdz.com/
- واتساب: https://wa.me/213655970064

تتضمن الصفحة خطط Offline وOnline، تجربة مجانية 3 أيام، دليل التشغيل، و10 لقطات حقيقية من داخل البرنامج.

## النشر

GitHub Pages من فرع main والمجلد الرئيسي. ملف index.html مستقل ويحتوي على HTML وCSS وJavaScript والصور المضمّنة.

لتحديث الموقع، استبدل index.html بالإصدار الجديد.
